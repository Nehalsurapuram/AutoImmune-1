## 6. Snippet for C7 (first stop by intended candidate kind)

```python
import json
G = ("v0", "v1", "v2", "v3")
rows = [json.loads(l) for l in open("results/evidence.jsonl", encoding="utf-8") if l.strip()]
latest = {}
for r in rows:
    if r["patch_mode"] == "scripted":
        k = (r["fault_id"], r["candidate_kind"])
        if k not in latest or r["timestamp"] > latest[k]["timestamp"]:
            latest[k] = r
for k, r in sorted(latest.items()):
    stop = next((g.upper() for g in G if r[g]["status"] != "pass"), "passed->" + r["decision"])
    print(k, stop)
```

ESCALATE (F04); slow → AUTO_APPLY (F06). `candidate_kind` is the file name the candidate was built under. It is **not** an independent label.
